# Shot list: "What If You Could See How Long Everyone Has Left?" (POV + whiteboard)
Direction by Elias, 2026-11-11. "On you" = Claude picks the best shot. Focus: camera movement + character placement (eye level, rule of thirds, depth).

| Narration | Mode | Shot |
|---|---|---|
